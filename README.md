# Sales Data Overview Dashboard 📊

This project is a **Sales Data Overview Dashboard** designed to analyze sales performance and present key business metrics using visual dashboards.  
The data used in this project was provided by my class teacher for learning and practice purposes.


## 🔍 Project Overview

The dashboard provides insights into overall sales performance, sales representatives’ contributions, order trends, and commission distribution.


## 🎯 Goal of the Dashboard

To analyze sales data and visualize important metrics that help in understanding sales performance and supporting better business decisions.


## ⭐ Features / Highlights

- Overview of total sales, total orders, and total commission  
- Sales analysis by sales representative  
- Daily order trend visualization  
- State-wise sales performance comparison  
- Item-wise quantity distribution  
- Commission analysis by sales representative  


## 🛠 Tech Stack / Technologies Used

- Power BI  
- Data Analysis  
- Data Visualization  
- Sales Dataset (Provided by Instructor)  


## 📈 Key Metrics Included

- Total Sales  
- Total Orders  
- Total Commission  
- Number of States Covered  
- Sales by Representative  
- Sales by State  
- Quantity Sold by Item  


## 📂 Dataset Information

The dataset contains sales-related information such as:
- Sales representatives  
- Order details  
- Sales amount  
- Commission details  
- Items sold  
- State-wise sales data  

The dataset is used strictly for educational purposes.
